# Generative-AI Use Disclosure

Generative AI tools, principally **OpenAI ChatGPT**, were used as assistive tools during the development and documentation of this project.

## What AI was used for

AI assistance included:

- drafting, editing, and restructuring manuscript and supplementary text;
- helping formulate methodological alternatives, reviewer-style critiques, and sensitivity-analysis plans;
- drafting and refactoring code;
- debugging and code review;
- generating documentation and repository structure;
- preparing figure-generation code and presentation layouts;
- assisting with literature-search queries and synthesis of methodological context.

## What AI was not treated as

AI output was **not treated as scientific evidence, a statistical result, or an authoritative source**. Numerical claims in the manuscript are tied to executable analyses, frozen outputs, versioned methodological audit records, and/or cited primary literature.

## Human responsibility and verification

The authors:

- defined the scientific questions and inferential targets;
- made the substantive methodological decisions;
- prospectively froze the official application specification and publication seeds;
- reviewed and verified code and outputs used to support manuscript claims;
- checked literature claims against primary sources where used;
- retained rejected analyses and methodological corrections in a versioned audit trail;
- take full responsibility for the accuracy, interpretation, and conclusions of the work.

No AI system is an author or assumes responsibility for the work.

## Code-provenance rule

This repository distinguishes **archived original scripts** from later **clean or reconstructed implementations**. AI-assisted rewriting/refactoring is never presented as if it were the historical source code that generated an archived result.

## Data boundary

No generative-AI output is used as a substitute for observed clinical data. The public repository contains no patient-level coordinates or empirical clinical hotspot geometry. The Geneva demonstration is semi-synthetic and uses public geography/population plus synthetic clinical spatial data.

## Suggested manuscript disclosure

> **Use of generative AI.** Generative AI tools (OpenAI ChatGPT) were used during study development to assist with manuscript editing, code drafting/refactoring and debugging, figure and repository preparation, and methodological/literature-organization tasks. AI-generated output was not treated as scientific evidence or as an independent analytical result. All study design choices, statistical specifications, code and numerical outputs supporting the manuscript were reviewed and verified by the authors, who take full responsibility for the work. Archived original analysis scripts are distinguished from later AI-assisted clean or reconstructed implementations in the public code repository.
