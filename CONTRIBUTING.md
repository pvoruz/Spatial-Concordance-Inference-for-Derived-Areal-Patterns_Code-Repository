# Contributing

Contributions are welcome after the initial paper release.

Please:
1. open an issue describing the methodological or software change;
2. preserve the distinction between archived historical code and new code;
3. add or update tests;
4. do not overwrite frozen official result files;
5. document any change to inferential targets, graph construction, classification rules, or null generation;
6. do not add patient-level clinical geography.

AI-assisted contributions should be disclosed when they materially affect code or documentation.
